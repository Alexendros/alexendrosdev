## Contrato actual `POST /api/contact`

Fuente: `src/pages/api/contact.ts` + `src/lib/contactSchema.ts` + `ContactForm.tsx`.

### Request

| Aspecto           | Contrato actual                                                                                                                                     |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Método            | Solo export `POST` (otros métodos: comportamiento Astro/Vercel por defecto; **sin** `405` + `Allow` explícito)                                      |
| Content-Type      | Esperado JSON; **sin** chequeo 415; `request.json()` falla → body `null` → 400 Zod                                                                  |
| Body (Zod)        | `name` string trim 2–100; `email` email; `company` opcional ≤100; `subject` 1–200; `message` 20–2000; `consent` literal `true`; `honeypot` opcional |
| Destinatario SMTP | Fijo servidor: From/To `operaciones@alexendros.dev`; cliente **no** elige destinatario                                                              |
| Rate limit        | Upstash sliding window 10 / 1 min, prefijo `alexendros:contact`, clave = IP (`x-forwarded-for` primer hop o `x-real-ip`)                            |
| Honeypot          | Si relleno → **200** `{ ok: true }` (sin enviar correo)                                                                                             |

### Respuestas HTTP observadas en código

| Caso                         | Status  | Body (resumen)                                                        |
| ---------------------------- | ------- | --------------------------------------------------------------------- |
| Validación fallida           | 400     | `{ error: <Zod flatten> }` — **expone paths/detalle Zod**             |
| Honeypot                     | 200     | `{ ok: true }`                                                        |
| Rate limited                 | 429     | `{ error: 'Too many requests' }` — **sin** `Retry-After`              |
| SMTP host/user/pass ausentes | **500** | `{ error: 'Service unavailable' }` + log `contact_smtp_misconfigured` |
| Envío OK                     | 200     | `{ ok: true }`                                                        |
| Error Nodemailer             | **500** | `{ error: 'Send failed' }` + log `contact_smtp_error`                 |
| Upstash no configurado       | —       | **Fail-open**: se omite rate limit y se continúa                      |

`SMTP_PORT`: `Number(env \|\| 587)`; no valida entero explícitamente (NaN posible si valor basura).

### UI (`ContactForm`)

- `fetch('/api/contact', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body })`
- Estados: idle / loading / ok / error
- Éxito: mensaje + enlace Cal.com; **no** dispara evento Analytics `contact_form_success`
- Error: mensaje genérico + pistas de campos

## Carencias observadas (para WP siguientes)

1. SMTP misconfig / send fail → HTTP **500** (objetivo WP-1/2: **503** genérico).
2. Rate limit **fail-open** si faltan `UPSTASH_*` (objetivo WP-2: fail-closed 503).
3. Sin 405 / 415 / 413 / `Retry-After` / correlation id en logs.
4. Respuesta 400 con `flatten()` Zod (detalle interno al cliente).
5. Sin tests unitarios del handler API (solo schema + e2e mock).
6. Sin evento cliente `contact_form_success` (Analytics presente en Layout).
7. Sin script npm `lhci` (solo invocación CI).
8. `engines.node` anclado a 20.x (issue #11 / WP-6).
9. Majors Dependabot diferidos (issue #12 / WP-7).
10. Posible mismatch nombre workflow CI ↔ `release.yml` `workflow_run`.
11. Env SMTP/Upstash en Vercel pendientes (issue #13) — **causa raíz** de fallo contacto en prod.
